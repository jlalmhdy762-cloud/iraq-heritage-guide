# Iraq Heritage Guide

A modern Arabic/English tourism and heritage website for Iraq's archaeological sites and civilizations.

## Features
- Home page with hero section and stats
- Civilization overview
- Archaeological site cards
- Interactive map using Leaflet
- Dedicated page for each heritage site
- Arabic-first design

## Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- React Leaflet

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Project structure
- `app/` – App Router pages and layout
- `components/` – UI and map component
- `data/` – site and civilization data

## Notes
This initial version focuses on Iraq's major heritage sites and civilizations, with a clear path to expand into more locations and richer content.
